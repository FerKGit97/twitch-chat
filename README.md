# Twitch Chat Overlay

Chat real de Twitch para usar como Browser Source en OBS.

## URL

Después de activar GitHub Pages:

`https://ferkgit97.github.io/twitch-chat/?channel=TU_CANAL`

Ejemplo:

`https://ferkgit97.github.io/twitch-chat/?channel=ferklives&max=12&time=0`

### Parámetros

- `channel`: canal de Twitch.
- `max`: cantidad máxima de mensajes visibles.
- `time`: segundos antes de ocultar cada mensaje. `0` = permanecen hasta que salgan por límite.

El fondo es transparente y el CSS está dentro de `index.html` para poder personalizarlo fácilmente.
